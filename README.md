# Аркан — сайт відпочинкового комплексу

Односторінковий сайт-візитка комплексу «Аркан» (Верховина, Карпати).

## Структура

```
index.html   — вся розмітка сторінки
style.css    — стилі
script.js    — мобільне меню (бургер)
```

Файли статичні, без збірки — можна відкривати `index.html` прямо в браузері для перевірки локально.

## Як залити на GitHub Pages

1. Створи новий репозиторій (або використай наявний), наприклад `arkan-site`.
2. Заливаєш ці три файли в корінь репозиторію (або в папку `/docs`, якщо так зручніше — тоді треба буде вказати це в налаштуваннях).
3. У репозиторії: **Settings → Pages**.
4. У розділі **Build and deployment** → **Source** обираєш **Deploy from a branch**.
5. **Branch**: обираєш `main` (або яка у тебе основна), папку — `/ (root)` або `/docs`, залежно де лежать файли.
6. Тиснеш **Save**.
7. Через 1-2 хвилини сайт буде доступний за адресою:
   ```
   https://<твій-юзернейм>.github.io/<назва-репозиторію>/
   ```

## Коли підключиш власний домен

1. У реєстратора домену додаєш DNS-записи:
   - Якщо домен кореневий (`arkan.com`) — 4 записи типу **A** на IP-адреси GitHub:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Якщо піддомен (`www.arkan.com`) — запис типу **CNAME** на `<юзернейм>.github.io`
2. У репозиторії: **Settings → Pages → Custom domain** — вписуєш свій домен, зберігаєш.
3. GitHub сам створить файл `CNAME` у репозиторії — не видаляй його.
4. Дай DNS 30 хв – кілька годин на поширення, потім онови сторінку Pages — з'явиться галочка **Enforce HTTPS**, увімкни її.

## Заміна фото на власні

Зараз усі зображення підвантажуються напряму з `verkhovyna.life` — це тимчасово, для демонстрації структури. Перед публічним запуском:

1. Завантаж власні фото (в оригінальній якості, стиснуті через [squoosh.app](https://squoosh.app) або TinyPNG, бажано у форматі `.webp`).
2. Постав їх у папку `/img` у репозиторії.
3. У `index.html` заміни `src="https://verkhovyna.life/..."` на `src="img/назва-файлу.webp"`.

## Що ще варто доробити перед запуском

- Вписати реальні ціни за номери (зараз placeholder: 1500 / 1800 / 2000 грн)
- Замінити меню-скани на текстовий список страв
- Додати favicon (`favicon.ico` у корінь + `<link rel="icon">` у `<head>`)
